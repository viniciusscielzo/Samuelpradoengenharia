# Samuel Prado Engenharia Civil

Site institucional premium desenvolvido em Next.js padrão, preparado para deploy no GitHub e na Vercel.

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Produção

```bash
npm run build
npm start
```

Na Vercel, importe o repositório e mantenha as configurações automáticas detectadas para Next.js.
